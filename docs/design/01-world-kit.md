# World kit and seasons

One asset set, many cities. A level is data (`src/shared/Content/Worlds/<World>.luau`) that places props from a shared kit; a **theme** recolours and redresses that same level. These are the patterns that make it work.

## Pattern 1: Palette swap (0 new meshes)

Every prop's faces sit in named palette cells (`w-*`). A theme ships its own 1,024 px gradient atlas with the **same layout** (generated by script from the tokens, see *Art style: how realistic*), so the client swaps `MeshPart.TextureID` and the whole city changes colour.

| Theme id | Name | Mood | What changes most |
| --- | --- | --- | --- |
| `city` | Sunny City | The default. Clean summer diorama. | — |
| `winter` | Holiday City | Snow on everything, warm windows. | `w-season`, `w-roof-a`, `w-grass` go white; `w-glass` glows amber |
| `spring` | Blossom City | Pastel facades, pink trees. | `w-season` blossom, softer walls |
| `autumn` | Harvest City | Orange canopy, low gold sun. | `w-leaf` orange-red, `light-sky` warm |
| `toon` | Toon City | Max saturation, cartoon. | Every role saturated; shadows off, `Lighting.Ambient` high |
| `neon` | Night City | Dark streets, lit signs and windows. | Dark walls, `w-glass`/`w-door`/`w-season` lit with `Material.Neon` |

Switch the page's theme to see every World preview recolour.

**Rules**
- A role means the same thing in every theme. Never reuse `w-accent-red` for something that is not a hero accent "because the hex is close."
- Rows 0–3 (32 cells) are shared roles. Rows 4–7 (32 cells) belong to the level for its heroes. A theme must fill all 64.
- Stand-in parts (no mesh yet) take `Part.Color` from the same token, so grey-box layouts already show the season.

## Pattern 2: Dressing slots (a few new meshes per season)

Some placements in a level are **slots**, not objects: `slot.small` (tier 1), `slot.medium` (tier 2), `slot.yard` (tier 3), `slot.street` (tier 4) and `slot.landmark` (one per plaza). The level says *where*; the theme says *what*.

| Slot | `city` | `winter` | `spring` | `autumn` | `neon` |
| --- | --- | --- | --- | --- | --- |
| `slot.small` | Ice lolly | Bauble | Painted egg | Mini pumpkin | Glow stick |
| `slot.medium` | Beach ball | Gift box | Flower crate | Hay bale (small) | Speaker cube |
| `slot.yard` | Paddling pool | Snowman | Blossom tree | Scarecrow | Neon arrow sign |
| `slot.street` | Ice-cream truck | Sleigh | Parade float | Pumpkin cart | Food truck (lit) |
| `slot.landmark` | Giant Inflatable Duck | Mega Tree | Hot-Air Balloon | Giant Pumpkin | DJ Stage |

Each theme ships 6–10 dressing props. Dressing never exceeds about 15 % of placements, so most of the city stays the shared kit.

## Pattern 2b: Theme overlays and hero variants (a theme that feels like an event)

Slots alone make "the city with snow". A launch or event theme can add two more layers, both data:

- **Overlay placements**: extra zones and fixed placements that exist only in that theme, laid on top of the base layout (a Christmas market in the Plaza, garlands across Market Street, snow piles at the edges).
- **Hero variants**: the theme maps a base hero to an alternate mesh (the Donut Food Truck becomes the Cocoa Truck; The Glass Tower gets a giant bow). A variant keeps the base object's tier, size (±10 %), collision class and coins, so gameplay is identical.

**Rules**
- Base layout + overlays together stay within the level's placement budget (about 1,400 for Downtown). Overlays take their share from slot and tier 1–2 zone counts, never from the ring gates.
- Overlays never block a base route: ring gates, small-only alleys, the drain tunnel and every spawn's sightline to a tier 5 landmark stay clear.
- Each theme passes the same bot-run pacing check as the base (tier times within ±20 s).
- Theme-only objects get their own collection-book page per theme (for example *Downtown: Holiday*). The page comes back every year with the theme, so nothing is "limited"; it can be finished next season.

Suggested data shape for a theme: `{ id, paletteAsset, lighting, weather, music, slots = { [slotId] = objectId }, overlays = { zones, fixedPlacements }, heroVariants = { [objectId] = assetKey }, bookPage }`. The level picks its active theme by id in data; switching is a content change, never code.

## Pattern 3: Weather and light (data only)

Each theme's `WorldDef.lighting` sets `clockTime`, `brightness`, fog and atmosphere from `light-sky`, `light-fog`, `light-ambient`. One `ParticleEmitter` attached to the camera (not the world) carries the weather: snow, petals, leaves, rain-free night sparkle. It is capped at 40 particles and turned off by Reduce motion.

## Pattern 4: Modular buildings

Buildings are assembled from a small set of modules, not modelled one by one. **Absorbable buildings are still one MeshPart each**; the modules exist in Blender so new buildings come together fast.

- Footprints on a 4-stud grid: 8 × 8, 8 × 16, 16 × 16, 16 × 24.
- Storey height 8 studs. Ground floors: shopfront, garage door, glass lobby, plain door. Upper floors: window bay ×2 or ×3, balcony.
- Roofs: flat with a `w-season` parapet cap, pitched (`w-roof-a`), or a rooftop extra (water tank, billboard, satellite dish, roof garden).
- Facade colour by role: `w-wall-a` for most, `w-wall-b` every other shop, `w-wall-c` on corners. Changing the role a building uses is how one module set gives a varied street.

## Pattern 5: Ground is Parts, props are meshes

- Roads, pavements, kerbs, plazas, park lawns: plain `Part`s with `SmoothPlastic` and `Color` from the `w-*` token (as `environment.blocks` already does with swatches). Cheap, recolourable, and never absorbed.
- Everything the ball can absorb is **one MeshPart** using the shared palette texture. One asset id per object type, so 40 traffic cones cost one mesh in memory.
- Big static scenery that is never absorbed (background skyline, the motorway flyover, the river wall) can be Parts or one merged mesh per block.

## Reusing it for new levels

| Level idea | Reuses | New |
| --- | --- | --- |
| Downtown (default) | — | The core kit plus 10 heroes |
| Beach Boardwalk | Kit tiers 1–4, food trucks, cars | Sand roles in rows 4–7, pier, lifeguard tower, ferris wheel |
| Suburbs | Cars, bins, mailboxes, trees, bikes | House modules with gardens, trampoline, school bus |
| Airport | Vans, buses, luggage, vending | Baggage carts, jet bridge, a plane as the finale |
| Space Port | All tiers via palette `neon` | Rocket finale, satellites |
