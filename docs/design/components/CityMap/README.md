# CityMap

The Downtown layout from above, drawn in palette roles so it recolours per theme: districts in rings, 12 doorstep spawns, heroes on the sightlines.

- **Consumer provides**: the world's zones and fixed placements (`Worlds/Downtown.luau` once written), the spawn points and the district names.
- **Use it** as the level brief and to check that every spawn can see a tier 5 landmark.
- **Do** keep each ring gated by something one tier up (bollards, then hedges and fences, then parked vans).
- **Don't** put tier 4–5 objects within 40 studs of a spawn; the first minute needs room to grow.
