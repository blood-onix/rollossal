# StyleCompare

The same fire hydrant in the three art styles considered for Downtown: A toy low-poly (the current pipeline), B stylised real (recommended, ringed) and C realistic PBR.

- **Consumer provides**: nothing; it is the art-direction reference for *Art style: how realistic*.
- **Use it** when briefing a modeller or judging a new prop: it should look like B.
- **Do** get realism from proportions, one bevel segment and the atlas gradients.
- **Don't** add per-prop textures, normal maps or dirt decals (C); they cost memory on phones and break the one-texture season swap.
