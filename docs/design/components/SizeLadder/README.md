# SizeLadder

The five Downtown size tiers drawn to scale: the ball at the start of each tier beside the objects it can just eat (`size ≤ 0.4 × diameter`).

- **Consumer provides**: the tier table from the world's `sizeTiers` (min diameter, name key, headline key) and 2–3 example objects per tier.
- **Use it** in pitch decks, the store-page "size contrast" thumbnail brief, and when checking that a new prop sits in the right tier.
- **Do** keep every tier chip's number beside its colour (`tier-1`…`tier-5`); colour is never the only signal.
- **Don't** add a tier between the five without retuning `starThresholds` and zone counts.
