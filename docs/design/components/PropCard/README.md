# PropCard

A prop's art sheet in the stylised-real look: the object in real proportions with bevel highlights and gradient shading, its tier, size and palette roles. Switch theme to see the same prop in every season.

- **Consumer provides**: the object id, tier, size (studs), the 2–4 `w-*` roles it uses and its one-line twist.
- **Use it** to brief a new prop before modelling in Blender, and in the asset review.
- **Do** shade with the atlas gradient (light top, darker base), catch a highlight on the bevelled top edge, and give every top face `w-season`.
- **Don't** use more than one hero accent per prop, words on any face, or chunky toy proportions.
